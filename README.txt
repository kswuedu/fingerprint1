FINGER IQ FINAL v8 PERSONAL ANALYSIS

핵심 변경
1. 새 검사 시작 시 이전 사람의 지문/결과 데이터를 완전히 초기화
2. 마지막 '지문 분석 시작'에서 단순 ARCH/LOOP/WHORL 문자열만 사용하지 않음
3. 각 손가락의 후보확률, 융선점수, 방향일관성, 판독신뢰도를 함께 분석 엔진에 전달
4. FingerprintEngine 2.0이 손가락별 후보확률을 혼합하고 판독품질을 보정하여 현재 검사자의 결과를 새로 계산
5. 따라서 새 사람을 검사할 때 이전 사람 결과가 재사용되지 않고 현재 촬영 데이터만 반영
6. 기존 컬러 상세 결과지 / 모바일 / PDF / 비밀번호 finger1004 유지

중요
이 변경은 '개인별 지문 데이터가 실제 계산에 반영되는 구조'를 강화한 것입니다.
